You can achieve this using Python's time module. What you're looking for is called a typewriter effect, combined with a simple CLI screen transition.

Instead of displaying everything instantly, the text appears gradually, creating that classic 2D adventure-game introduction.

1. Recommended implementation

python
import time
import os

def main_menu():

    os.system("cls" if os.name == "nt" else "clear")

    title = """
    ################################################
    #                                              #
    #          MYSTERY ISLAND ADVENTURE            #
    #                                              #
    #              THE LOST TRAVELLER              #
    #                                              #
    ################################################
    """

    for character in title:
        print(character, end="", flush=True)
        time.sleep(0.03)

    time.sleep(1)

    prompt = "                  [ PRESS ENTER ]"

    for character in prompt:
        print(character, end="", flush=True)
        time.sleep(0.08)

    print("\n")

    time.sleep(0.5)

    message = "             >>> YOUR ADVENTURE BEGINS <<<"

    for character in message:
        print(character, end="", flush=True)
        time.sleep(0.06)

    print()
2. Understanding the transition
Here are the important parts:

Code

Purpose

import time

Allows you to introduce delays.

time.sleep(0.03)

Waits 0.03 seconds between characters.

flush=True

Displays each character immediately.

os.system("clear")

Clears the terminal on Linux/macOS.

os.system("cls")

Clears the terminal on Windows.

time.sleep(1)

Pauses before displaying the next message.

3. Experiment with the animation speed
You can adjust the delay to achieve different effects:

Delay

Effect

0.01

Very fast

0.03

Smooth typing

0.06

Slow cinematic typing

0.10

Dramatic typing

0.15

Very slow typing

My recommendation: Use 0.03 for the game title and 0.06 for important messages.

4. A programming tip
As your Mystery Island game grows, consider creating a reusable function:


python
def typewriter(text, delay=0.05):
    for character in text:
        print(character, end="", flush=True)
        time.sleep(delay)
    print()
Then you can simply call:


python
typewriter("A storm approaches the island...", 0.06)
typewriter("You wake up on an unfamiliar shore...", 0.08)
This way, you won't have to write the same animation loop for every scene.

My advice: Build your own reusable animation functions. They'll make your text-based adventure feel much more like a classic retro game.
